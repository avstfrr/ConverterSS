# ConverterSS

Конвертер систем счисления (Лабораторная работа №1). 
Утилита с графическим интерфейсом (GUI) для математически точного перевода чисел между системами счисления от 2-й до 16-й.

## Особенности архитектуры
- Алгоритм перевода написан вручную (деление остатком для целых, умножение на основание для дробей) без использования стандартных функций конвертации Python (таких как `bin`, `hex` и т.д.).
- Независимая обработка целой и дробной части числа.
- Графический интерфейс реализован на встроенной библиотеке `tkinter`.
- Перехват и изоляция ошибок ввода (валидация данных на лету).

## Требования
- Python 3.x
- Встроенная библиотека `tkinter`

## Использование
1. Введите исходное число (поддерживаются как целые, так и дробные).
2. Укажите исходную систему счисления (от 2 до 16).
3. Укажите целевую систему счисления (от 2 до 16).
4. Нажмите "Сконвертировать". Программа обработает вычисления и выведет результат, либо сообщит о синтаксической ошибке в введенных данных.
